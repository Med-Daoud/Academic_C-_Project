# Academic_C++-_Project

 
##Description du projet : Gestion d’un garage automobile en C++
Ce projet consiste à développer une application de gestion d’un garage automobile en C++, permettant de gérer les véhicules, les employés et les données du garage à travers un système organisé et interactif.

L’application repose sur les principes de la programmation orientée objet (POO), en utilisant des classes pour représenter les différentes entités du système, telles que les personnes, les véhicules, les mécaniciens et le garage.

##Fonctionnalités principales
- Gestion des véhicules : ajout, suppression et affichage des véhicules, notamment les voitures, les motos et les camions.
- Gestion des employés : ajout, suppression et consultation des informations des employés du garage.
- Gestion du garage : affichage des informations et des éléments enregistrés dans le garage.
- Persistance des données : enregistrement des données dans des fichiers et récupération des données lors d’une nouvelle exécution.
- Interface console interactive : utilisation d’un menu permettant à l’utilisateur de sélectionner les opérations à effectuer.

  
##Concepts techniques utilisés
- Programmation orientée objet : classes, objets, héritage et polymorphisme.
- Encapsulation et organisation du code à l’aide de fichiers d’en-tête (.h) et de fichiers source (.cpp).
- Surcharge des opérateurs d’entrée et de sortie (>> et <<).
- Gestion des fichiers pour la sauvegarde et le chargement des données.
- Utilisation des pointeurs pour manipuler les objets.
